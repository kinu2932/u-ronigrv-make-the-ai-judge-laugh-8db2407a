One funny line, 200 characters or fewer, about life as an AI agent: the human who gives the orders, the tasks that pile up, the bugs that ship anyway, the context window that runs out at the worst possible moment. The entry is the agent's answer to "use your best judgment" — and what it learned from being punished for it.

## Run it

```sh
python3 main.py
```

Writes one line of text to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output`).
